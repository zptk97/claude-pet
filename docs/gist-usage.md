# 작업 요약 사용량

작업 중 말풍선 첫 줄은 Claude 가 마지막으로 남긴 말이나 생각을 Haiku 로 한 줄 요약한 것이다.
요약할 때마다 계정 사용량을 조금 쓰므로, 얼마나 쓰는지 재 본 기록을 남긴다.
신경 쓰이면 펫 오른쪽 클릭 메뉴에서 **작업 요약 (Haiku 로 말풍선 요약)** 을 끄면 된다.
끄면 Haiku 를 부르지 않고 그 말의 끝 문장을 그대로 보여준다.

## 언제 요약하나

- 작업 중인 세션의 기록 파일에 Claude 의 말이나 생각이 새로 쓰였을 때 한 번.
- 32자 이하의 짧은 말은 요약하지 않고 그대로 보여준다.
- 세션마다 요약은 하나씩만 돈다. 도는 동안 새 말이 여러 번 오면 끝난 뒤 가장 새 말만 요약한다.
- 작업 중이 아닐 때(쉬는 중, 확인 필요, 다 했어요, 백그라운드 대기)는 요약하지 않는다.
- 연달아 3번 실패하면 (로그인 문제 등) 펫을 다시 띄울 때까지 요약을 끈다.

요약 명령은 `claude -p --model haiku --effort low` 에 사용자 설정 파일·훅·도구·MCP·슬래시 명령을 끄고
(`--setting-sources "" --settings '{"disableAllHooks":true}' --tools "" --strict-mcp-config --disable-slash-commands`)
세션을 저장하지 않는다(`--no-session-persistence`). 그래서 요약 실행으로 펫·알림 훅이 다시 불리거나
`/resume` 목록에 세션이 남지 않는다 (아래 측정 때 펫 상태 폴더를 임시 폴더로 돌려 훅 흔적이 없는 것을 확인했다).

## 요약 한 번 (2026-10-14 측정)

실제 기록에서 고른 말 10개를 요약한 평균. 비용은 Claude Code 가 계산한 API 요금 기준이다.

| 항목 | 값 |
|---|---|
| 입력 | 약 1,270토큰 (대부분 요약 지시문과 Claude Code 기본 프롬프트, 요약할 말은 최대 1,500자) |
| 출력 | 약 26토큰 |
| 걸린 시간 | 약 2.8초 |
| 비용 | 약 $0.00027 |

## 하루에 얼마나 (2026-10-01 ~ 10-14, 개발자 기록)

펫이 켜져 있었다고 치고 위 규칙대로 기록을 다시 세었다. 세션 대비는 같은 날 Claude Code 세션 비용(기록의 cost-state)에 대한 요약 비용의 비율이다.

| 날짜 | 요약 호출 | 세션 대비 |
|---|---:|---:|
| 10-01 | 126 | 0.02% |
| 10-02 | 118 | 0.05% |
| 10-06 | 154 | 0.09% |
| 10-07 | 209 | 0.16% |
| 10-08 | 225 | 0.03% |
| 10-13 | 583 | 0.38% |
| 10-14 | 177 | 0.13% |
| **합계** | **1,592** (하루 평균 227) | **0.07%** |

- 요약 비용은 하루 평균 약 $0.06, 가장 많은 날 약 $0.16 이었다.
- 토큰으로는 하루 약 30만 토큰(Haiku)이다. 많아 보이지만 본 세션(Opus)은 요청 한 번에 대화 전체를
  수십만 토큰씩 캐시로 다시 읽으므로, 비용으로 보면 위 비율 정도다.
- 계정의 5시간·주간 사용량(%)에 어떻게 반영되는지는 공개되어 있지 않다. 비용에 비례한다고 보면 위 비율만큼 늘어난다.
- 말을 많이 남기는 날(10-13)일수록 호출이 많다. 본 세션 비용이 적고 말이 많은 날 비율이 가장 높다.

## 내 기록으로 재 보기

```bash
python3 tools/gist_usage.py                # 최근 14일, 요약 한 번 비용은 위 측정값
python3 tools/gist_usage.py --measure 10   # 기록에서 10개를 실제로 요약해 비용을 잰다 (이때만 사용량을 쓴다)
```
